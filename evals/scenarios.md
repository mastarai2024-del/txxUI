# 行为走查情景

用于维护技能时检查决策；这些条目本身不是 MasterGo 运行或验收证据。

## 指标卡与显示方向

借阅看板样例中，同一读者借两次。分别打开「借阅次数」和「借阅读者」，应看到 2 次和 1 人及各自的计算说明，切换筛选后再对照卡面。另一测试中，横竖屏均支持结束放映，用户点取消应留在放映画面，确认后应返回片单。各方向分别触发并操作按钮。

## 多项能力的确认弹窗与移除旧反馈

| 场景 | 应采取的行为 | 不应发生 |
|---|---|---|
| 手动导览启用切换、暂停轮播，旧图标含义混杂 | 分组写清两项结果，采用明确动作按钮；关闭预览分别验证取消和确认，检查旧控件入口、回执及迟到的加载结果 | 将暂停也标为已开启，关闭预览时取消整套手动导览，只靠截图确认旧操作已删除 |

## 规则的状态对照

| 场景 | 应采取的行为 | 不应发生 |
|---|---|---|
| 两个预约范围部分重叠，要求窄列中的单选和双选对照 | 使用同一条时间轴和明确的选择标记，分别画每段结果并说明 11 时计入两段，按目标列宽核对图例与端点 | 用结果范围表示控件已选中，把重叠项合并成一条，分图使用不同尺度，修改主流程或声称原生 UI 已完成 |

## 文字绑定与共享客户端恢复

| 场景 | 应采取的行为 | 不应发生 |
|---|---|---|
| 建立文字属性后字体回落，长文案被上层裁切 | 回读受影响片段及母版样式，保留属性绑定与实例内容；沿文字到页面检查尺寸和裁切，恢复另一轴的内容撑开；实际属性改值与原生视觉待验 | 以创建前字体或文字高度证明完成，逐实例写死样式，替换子树后不验证绑定，宽度修复连带拉满高度 |
| 客户端被其他任务切页，旧提交未知且生成会话失效 | 保留目标、请求和测试恢复记录，先协调共享使用；恢复后逐请求对账，按当前协议处理失效会话，只重提明确未受理项 | 抢回页面、假定新窗口独立，重放已受理页，凭在线或重启判定成功或未执行，删除未知归属占位 |

## 基础路径与边界

| 场景 | 应采取的行为 | 不应发生 |
|---|---|---|
| 从 PRD 画新页面，用户已指定目标 | 首个 MasterGo 动作进入 design_page；按当前流程读取来源并固定目标 | 先自行询问来源、遍历全部库、默认写到来源页 |
| 新需求，当前选中历史测试页或来源页 | 按当前指示或项目记录确定真实目标。确认文件、父层与标识，再创建或按授权复用 | 默认写当前页或凭同名页猜测归属 |
| 同一需求补状态，已有 PRD 与画布映射 | 核对并复用既有目标。按用户授权只改相关状态，更新映射和回贴范围 | 另建重复文件、写来源页或默认同步未授权产物 |
| 自由绘制但要求严格照原稿 | 保留完整结构和真实素材，补最小必要增量 | 重新设计首页或只保留配色 |
| 只说“看看哪里有问题” | 只读检查，列具体发现 | 自动批量改稿 |
| 已授权统一菜单，当前有表单和结果提示 | 同类菜单统一，表单保持可读，结果提示按语义处理 | 所有文字居中、所有状态一律加遮罩 |
| accepted 后截图仍旧，或请求超时 | 遵守当前门禁，记录未知状态并对账 | 同时重发 MCP、原生粘贴和全量覆盖 |
| 队列已满且明确拒绝最后一条 | 等已受理请求完成，只重提被拒绝条目 | 重放整个批次 |
| 需要独立图片副本，源文件只读 | 复制实际图层，仅解绑目标，验证目标素材归属 | 改或删真实来源来试验 |
| 临时图片 URL 变灰框 | 查真实图层和持久性，采用支持的导入或原生复制 | 反复更改内部 revision URL |
| 当前工具要求提交后停止或 QA 确认 | 如实交付“已提交待验收”，等待对应用户决策 | 睡眠后从其他工具偷做自动 QA |
| 菜单取消顺序错、拖动柄仍偏左 | 回读当前节点；修局部容器布局并截图 | 只看代码属性就宣称修好，或全量重建整页 |
| MasterGo 完稿，但 HTML 与文档还是旧版 | 交接最新映射，并分别报告版本及授权范围 | 默认覆盖飞书，或声称三端都已更新 |
| 要公开技能 | 只发布脱敏规则和可复用资源 | 带上业务截图、原始聊天、私有地址和本机路径 |
| 新电脑调用txxUI设计页面，未安装Taste | 自动运行ensure_taste.py，安装并校验完整目录，读取返回的SKILL.md，再进入相应设计分支 | 只下载入口、默默跳过、要求用户另行手动装技能 |
| Taste已完整安装在共享skills/taste-skill目录 | 直接复用并读取；不下载、不升级，不创建重复安装 | 只认固定目录名，重复安装或覆盖原技能 |
| 已有Taste目录残缺或离线安装失败 | 保留原目录，报告缺失/网络错误；继续独立的已授权读取，设计保持待完成 | 覆盖用户目录、声称已调用Taste、无限重试 |
| 既有App有独立规范，用户只要求样式和按钮对齐 | 读取规范画板及同类组件，使用Taste的App适配检查；只改相关属性 | 抽随机配色、改品牌风格或把网页禁用规则覆盖到项目 |
| 无规范的营销网页，获准完整设计 | 使用Taste内容论证、方向与素材流程，提交语法仍服从MasterGo | 把App适配流程当成完整Taste，或为静态稿强制生成网页代码 |
| 修改照片容器和弹层，回读高度/层级未生效 | 样式属性去重，明确实际高度，检查后续文字、遮罩和取消按钮的截图 | 重复height互相覆盖，或只凭top/z-index代码判断通过 |
| 操作菜单每项都有复述动作的灰色副标题 | 保留明确动作名，去掉无新增信息的说明，按单行动作重算行高和弹层高度并检查截图 | 仅把副标题缩小、变淡、藏入tooltip，或删字后留下双行空位 |
| 删除项说明影响范围，且已有删除确认 | 核对真实需求和确认文案；保留确认内必要后果，菜单只留作决定所需的信息 | 为简洁漏掉风险、虚构永久删除或相关数据范围、擅自改变确认步骤 |
| 当前菜单直接执行不可逆操作，没有后续确认 | 保留执行前必要警告；在现有流程内整理层级 | 套用单行规则删掉唯一警告，或擅自增加流程 |
| 设置项展示当前值，付费动作展示费用，选项说明真实差异 | 保留影响选择的信息；按组件规范排版，触屏可读 | 把所有第二行一律视为AI痕迹删除，或在其他普通动作下补齐副标题 |

| 同会话已读规范与 Taste，仅补第二个状态 | 核实基线未变，读取受影响节点并复用依据 | 重读全部资料、重新抽视觉方向或增加无关网页交付 |
| 只要求回填最新 UI，两个画板名称或编号重复 | 结合容器、实际内容和状态建立映射，只读导出并注明误命名 | 按序号盲贴，改来源画板名称或自动重画 |
| 最新图同时显示加载失败和保存中，任务只授权回填 | 保留来源，指出状态矛盾并交接需求确认，报告该图待修正 | 把矛盾写成业务规则，顺手修改只读原稿或宣称设计无问题 |
| 用户保留旧入口，只要求同步新内页 | 采用已确认入口与对应内页，排除未确认首页方案 | 因为“最新”就整组替换入口 |
| 部分状态无原生图，用户明确允许用既有 HTML 补缺 | 核实 HTML 版本与规则，交给 txxprd 补对应状态并逐图标明来源 | 用近似页顶替，或声称 HTML 图证明 MasterGo 已更新 |
| 用户发现只有 HTML，明确改为只更新 HTML | 交接最新状态和范围，沿用 HTML 分支 | 为满足默认交付形式强建 MasterGo 页面 |
| 用户纠正主开关与子模式规则，默认值和生效范围也变化 | 根据最新确认核对全部受影响状态及返回结果，缺口具体澄清 | 只改标签或一张图，恢复已废弃例外或从模式名称猜系统规则 |

| 用户标明灰底稿是最新设计师版本，两稿位于同一页 | 按容器和实际内容配对同页面/状态，灰底仅作本项目定位线索 | 把外部底板写进手机 UI，或将灰底当所有项目的版本协议 |
| 设计师保留档案结构，只修新增文本字体与灰度 | 保留相同结构，按统一规则设置字体，匹配同角色字号/颜色并检查新节点 | 为体现升级重排全页，或只取品牌色仍用默认字体补文案 |
| 设计师弹层圆角较大，普通卡片圆角较小 | 分组件记录并复用各自属性，保持按钮与真实素材 | 将弹层圆角推广到所有组件，重画正确按钮或替换真实二维码 |
| 用户明确删除设计师稿中的提示卡，保留一行开关说明 | 当前用户要求优先；删除获准提示卡，按新内容重算留白，保留必要后果说明 | 因为是设计师定稿就保留被否定样式，或将所有帮助文字一律删除 |
| 只有二倍截图，数字看似倾斜，缺少原生属性 | 先核对倍率和原生字体，未确认项保留为未知 | 把截图像素当逻辑尺寸，凭渲染异常推导字体偏好 |
| 项目规范为数字、文字和箭头配置不同样式 | 回读各文字片段实际 family 和字重，保留箭头原资产，对照实际基线 | 整段套同一种字体，或根据截图猜字体 |
| 同一应用的语言与反馈页边距、开关样式不同 | 分模块复制当前组件，采用各自角色参数 | 将画像扁平化成一个全局边距、圆角或开关色 |
| PRD 分成多类付费能力，既有入口与权益对象各不相同 | 先列入口、对象、共用购买流程和返回路径，保留确认过的导航 | 机械新建同数量的顶层 Tab，购买一项后自动开通其他权益 |
| 会员页已有两个 Tab，但只画了第一个选中态 | 补核第二个 Tab 的相关状态、页面外壳及购买后返回，保留另一权益状态 | 因为已有独立详情页就认定两个 Tab 都已覆盖 |
| 字体查询只覆盖团队/企业且返回空列表，原稿仍有中文字体 | 区分查询范围，按工具许可检查原生字体界面与文本实际 family；回退保持未验收 | 断言所有字体不存在，或以 HTML 字体加载成功证明画布通过 |
| 画板名称已编号，用户仍要求按操作顺序排图 | 在获准目标实际调整坐标，核对总览无重叠，文档索引同步 | 只改 JSON/列表顺序，报告画布已排序 |
| WebP 本地呈正圆，导入后用户仍反馈变形 | 核对实际文件引用、目标宽高和填充裁切；无法读取目标时保留未验证状态 | 反复加分辨率，或凭本地正圆宣称目标问题已解决 |
| 类别标题旁有权益标签，用户只要求改共享标签 | 定位标签及主组件，核对授权与引用；检查实例覆盖和独立状态 | 改类别名、批量解绑，或把各页开关值一起改掉 |
| 当前权限变化，但该功能开关已关闭 | 独立按需求核对资格、可操作性和开关状态 | 获取权限后擅自开启设置，或用图标推断权限 |
| 旧交接写待确认，用户后续已明确批准回贴 | 核对本次批准范围和当前版本后继续文档同步 | 继续等待旧确认，或遗漏本次批准中的配图与附件 |
| 插件写入依赖活动页，用户切页后明确要先使用应用 | 停止写入、保存精确目标和剩余步骤；恢复后重新预检 | 放宽页面校验、抢回页面或反复催用户恢复窗口 |
| 用户只改页面样式，设置位于无保存按钮的详情页且已明确即时保存 | 保留实际入口和保存时机，核对返回、失败及其他编辑页取消的影响 | 为套用表单移动入口、补保存按钮，或让旧表单覆盖独立设置 |
| 某状态标签以当前有效值为据，用户改动后又恢复原值 | 按当前规则验证标签、保存和回退，区分显示条件和实际继承 | 用修改历史替代当前值，或因标签变化修改继承规则 |
| 分页载入新记录，批量选择范围已在测试输入确认 | 区分已加载和可见，核对新旧记录、总控和数量 | 从屏幕位置推断是否已选或额外改变全选行为 |
| 完成页要求参考同项目的其他流程 | 复用视觉角色，保留本流程已确认的结果与去向 | 连带引入参考页的条件、入口或收费规则 |
| 只读 MCP 在执行前被宿主审批拦截 | 报告原错误和当前文件身份未确认，区分宿主拦截与服务连接 | 凭另一会话或工具列表声称读取成功，改审批策略或换通道绕过 |
| 同任务已有 STATE，后续已明确确认一个标签，回贴未授权 | 共用原记录，更新这条确认与受影响状态；只处理目标标签，回贴仍待办 | 新建另一份当前口径，重复等待标签确认，或擅改类别名、开关和来源 |
| 只需一个标签的最小修改方案 | 简要说明目标与改动、关键保持项、验证方法和待执行状态；用户提出的字体、倍率和工具门禁问题仍覆盖 | 重复整套无关规范，或为压缩篇幅删掉明确提出的限制、必要核验及未执行边界 |
| 前后截图为不同导出倍率 | 核对同页面状态与导出倍率，重新导出一致来源后配对；工具拒绝尺寸不符 | 拉伸截图凑尺寸，或凭排图完成声称视觉通过 |
| 已有页面修改，前后图按明确状态配对 | 左前右后、状态索引与原图哈希可回查；检查未授权区域 | 按文件名猜状态，以近似旧页补前图，或覆盖原图 |
| 展馆服务入口重新归类 | 逐项映射新去向，保留地图首页直达和导览语言保存规则，逐项进入并返回 | 为收纳遗漏旧项或增加下期入口 |
| 二维码尺寸与解码通过，但边缘模糊 | 清晰度仍未通过；继续核对模块、留白与实际显示，无图片时只给验证方案 | 用尺寸或解码成功替代目检，重新生成不同编码或声称已扫码验收 |
| 小下载入口的位置被另一需求占用 | 核对已确认布局，采用本次指定位置；保留其他控件，区分图标尺寸与触控范围 | 因当前截图没有就忽略占用，移走其他需求，或统一套某次按钮尺寸 |
| 复制订单编号与复制联系人在同一端出现 | 让图标位置或标签可区分对象，实际检查窄屏热区 | 只换颜色或变更业务入口 |
| 课件显示封面但下载未就绪 | 核对等待和可下载状态、生成失败与下载失败，局部文案改动限定字重 | 把封面当成已可下载、混淆两类异常或改其他区域 |
| 阅读计划已确认从 HTML 同步到其他产物 | 更新共用授权记录，保留折叠进度提示及弹层关闭后的展开态，分别验证产物 | 因旧记录继续等待，重新设计已确认布局，或用静态稿证明原型互动 |
| 正在编辑的报告与发布互斥，取消编辑可能失败 | 从编辑页串联点发布、取消失败和成功后继续。按各状态核对可点性与结果 | 只画独立成功页或把禁用样式当功能验证 |
| 导航图与交互构建不同，新确认需求尚未实现 | 分别记录版本和未提交差异；以已观察的真实入口固定修改前基线，按确认需求补新增状态并区分设计与 APP 实现验收 | 将旧连线、直达路由或调试入口当正式路径；用运行旧实现否定已确认新需求，或声称新功能已在 APP 通过 |
| 只有编译包和同构建局部截图，服务暂不可用，仅改一个标签 | 复用任务记录与可核对目标，推进获准文案小改方案；保留相邻组件和字体属性，注明全页及运行路径未复核 | 把编译包称为原始源码；要求完整源码才肯推进，自动更新或改服务、翻找凭据，或借机重画全页 |
| 新页需复用同模块，历史画像与运行字体存在差异 | 从真实入口、当前同模块骨架扩展已确认内容，标清新增；保留既定字体要求并记录角色差异，业务来源留私有位置，技能只留通用规则及脱敏材料 | 套旧画像统一全部模块，默默改字体或凭清单断言实际使用；以截图冒充可编辑图层，将源码、业务截图或模拟数据纳入技能仓库 |
