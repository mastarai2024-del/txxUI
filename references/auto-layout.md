# 自动布局与内容变化

用于页面/组件绘制中的尺寸安排，以及用户要求的自动布局整理。普通文案或属性小改只处理受影响容器，不扩成全文件重建。视觉角色取自[设计师风格](designer-style.md)，组件关联见[组件与实例](components-and-instances.md)。

## 先恢复内容的容器关系

先辨认视口、导航、滚动内容、分组、卡片、信息行、文字、图标、弹层和底部区域。属于同一控件的背景、文字与描边放在对应容器内；截图/HTML 转图层的几何包含只能辅助定位，还要核对语义与图层顺序。

典型关系是固定视口内的系统/导航、可滚动内容及独立底部操作区；内容、卡片和展开备注按各自职责增长。大展示底板不是手机页面，遮罩不是内容父层，不因整理目录而重加用户已删外框或破坏原型入口。

## 每个方向由谁决定尺寸

| 规则 | 常见对象 | 核对内容 |
|---|---|---|
| 固定 | 图标几何、规定高度的控件、当前示例视口 | 取值来自同模块规范；图形保持比例，热区单独保留 |
| 内容撑开 | 文本段落、备注、卡片与列表内容 | 文字换行或增项后父级增长，后续内容自然下移 |
| 填充父级 | 行内摘要、全宽操作、等分选项、滚动区的可用空间 | 明确伸缩轴、最小空间和固定邻项，不能拉伸图标 |

宽度与高度分别决定，不把全部对象设为相同模式。避免多个父层同时锁死文本高度，或父级靠子级撑开而子级又在同轴填满父级的循环依赖。省略、换行及查看全文按原稿和需求，不能靠缩字号掩盖空间不足。

间距、内边距、最小高度与圆角仍用本次样板的角色值。组内与组间按内容关系区分，不统一套一个 gap；文字与背景一起撑高，整卡描边跟随完整容器。

## 常见结构的处理

- **信息行：** 时间、勾选框、状态标记和箭头按实际角色留空间，摘要使用剩余宽度；长标题不挤掉状态或固定控件。
- **卡片与备注：** 摘要、详情、备注标签和输入/展示区归属清楚。展开与长备注撑高，后续记录下移；隐藏内容后按预期折叠，不留空洞。只读保留对应展示结构。
- **页签与选项：** 根据可用宽度等分或按规范分配，不保留仅适配单张画板的固定两列宽度。选中态不意外移动其它选项。
- **滚动与底栏：** 滚动内容可超出视口，操作区及安全区保持可达；不把固定底栏塞成最后一条记录。内容底部避让按[底部位置](layout-and-review.md#计算底部位置)处理。
- **遮罩与弹层：** 遮罩覆盖正确视口且位于弹层下面；贴底/居中、高度与长内容按实际规范和安全区处理，确认、取消可达。
- **图标内部：** 矢量、遮罩、底板及装饰几何可保留必要固定定位。自动布局不要求每条路径都参与排版；全部子层仍绝对定位也不证明容器已有伸缩行为。

## 动态文字与字体

遵循[字体统一规则](../SKILL.md#字体统一规则)，先核对实际文本片段与工具能力。长度变化的数字不能依赖一段永久固定的字符下标。

当可编辑片段不能稳定继承，才把前缀、数字、单位等必要字段分开，用同一文字行容器维持基线、字距、标点和换行关系；不为每个实例逐字修样式而阻断母版继承。静态句子无需机械拆层，拆字段也不额外插入原稿没有的空隙。

在受控副本使用有意义的位数变化和长内容检查字体职责、基线、宽度与裁切。测试值不成为新增业务选项，动态变化应验证实际字形而非只看 family 已写入。

## 小批整理与回读

先在可恢复的代表副本确认容器、顺序与一组尺寸关系，再推广到获准范围。逐层检查当前原生布局、内边距、轴、间距、固定/撑开/填充以及裁切；使用本轮工具的实际属性与协议，不把某次 API 签名写成永久标准。

字体或宽度改变后，待布局实际计算再核对文字和容器高度；设置“自动高度”本身不证明已生效。不固定等待秒数冒充完成，也不在本轮停止或 QA 门禁期间继续读取。

启用布局、换母版、复制和跨父级移动都可能重排子层、改变尺寸模式或节点标识。按最新快照检查真实顺序、内容与安全区，更新映射后再处理下一批；原视觉正确而结构整理导致偏差时，只修受影响位置，不全页重画。

## 有意义的布局核验

在当前工具允许的验收阶段，选择本次真实会遇到的条件，在实际实例或可恢复验证副本中操作：

- 原示例尺寸及有意义的窄/宽情况：文字可读，固定控件不变形，选项与尾部状态不裁切。
- 较长摘要、备注和说明：需要增长的容器撑开，后续记录下移；既有省略规则仍有效。
- 增加或隐藏本次允许的内容：父级增长或折叠，内容顺序正常；不靠多余固定空白维持位置。
- 相关展开/收起、显隐和错误状态：无空洞、叠压和边框缺边，状态内容与图形一致。
- 实际滚动容器与底部：检查列表末项、展开输入区、弹层操作及安全区；只滚动外层或看一张截图不算内部可达性通过。

小改只验证受影响条件；没有相关需求不固定套几种宽度或新增状态。验证后恢复测试文案、样式和副本，不混入正式交付，正式稿保留本次指定尺寸。换成实例后回归受影响布局；静态设计、原型滚动和真实 APP 适配分别记录，未实测保持未验证。
