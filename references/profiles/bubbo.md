# Bubbo 设计师风格档案

采样日期：2026-10-22。适用于 Bubbo / 巴布 App；其他项目不自动使用。本档案学习单页中的控件和视觉细节，页面结构、屏内布局和画布编排继续服从需求与用户已认可方案。

## 来源与可信范围

已核对项目设计规范，以及合规正式稿20个状态、登录/绑定/配网最新版 V2 的22个状态、报告 AFTER 的3个状态；另取5个 AI 合规状态作对照。状态总数不代表独立样本数。代表页已读取原生截图，其他状态以实际节点属性为证；没有逐张视觉验收全部页面。

原型、AI反馈、合规测试和旧版本分组不作为风格来源。合规页内的截图原型及归属不明的复制稿也排除。V2区域内的 Before 行不纳入。原始图、精确文件/页面/节点、测量台账及指纹留在项目私有资料中；本档案使用来源别名：

| 别名 | 来源家族 | 用途 |
|---|---|---|
| S | 项目设计规范 | 栅格、圆角、字体与状态声明 |
| C-mode / C-form | 合规的模式选择、模式设置与密码表单 | 头像、嵌套说明面、按钮、输入 |
| C-dialog / C-list / C-profile | 合规的告知、确认、人物/通知、资料编辑 | 弹窗、列表、状态、素材细节 |
| V-login / V-network / V-profile | 最新版 V2 登录、配网、资料与结果 | 数字字体、表单状态、轻提示、列表密度 |
| A-report | 报告 AFTER 的首页、健康与语言报告 | 容器分层、语义色底、指标字体 |
| AI-compare | 合规测试的5个对应状态 | 只作差异对照，不提高规则置信度 |

这是采样基线，后续使用先核对当前规范与所需组件锚点。用户指定的新正式稿优先；变更只更新相应条目。

## 视觉取向

功能界面以黑、白和浅灰组织信息，用圆角和底色变化表达层级。品牌暖色主要出现在首页真实场景、Bubbo形象、头像圈和编辑点；健康报告用薄荷绿，语言报告用浅蓝。主体控件克制，小部件带一点亲和感。

这种风格依赖真实素材与局部比例。把所有按钮换成暖棕色、给所有卡片加阴影，或用通用小图标代替Bubbo头像，都会偏离已采样的正式稿。已有AI稿中一致的输入框、按钮和页面底色直接保留。

## 基础规则

以下数值为设计单位，采样手机画板为375×812。跨尺寸保持控件角色与内部关系，宽度按可用容器计算，不整页同比缩放。

| 角色 | 已确认或观察到的参数 | 来源与使用边界 |
|---|---|---|
| 基准间距 | N=8；常见内部层级16、弹窗内缩24 | S明示；10等局部例外保留 |
| 圆角层级 | 8 / 16 / 32；圆形和胶囊另算 | S明示，C/V/A实际佐证；小内容面r16、大弹窗/部分外卡r32 |
| 中文主体 | Noto Sans SC | S + C/V/A；用当前get_fonts返回的精确family |
| 英文/数字角色 | 钉钉进步体；节点常见family为DingTalk JinBuTi | S + V-login；手机号/验证码等，不用于全部中文 |
| 普通导航标题 | 16/22/500；#333或黑 | C/V常见；部分资料/设备模块18/22为局部变体 |
| 字段/分组标题 | 14/17或20/500；#333 | C-form、C-list、V-network |
| 操作文字 | 14/20/500 | C/V按钮与操作菜单 |
| 常用说明 | 12/17或18；#666 | C/V；源稿11/16为更紧凑变体，长规则优先可读性 |
| 登录标题 | 28/38/700；配网页标题24/38/700 | V-login / V-network，不能套到普通导航 |
| 报告指标 | 22/32/600 | A-report局部角色，不能套到所有数值 |

规范列出的字号还有40、28、24、16、14、12、11、10。它是角色目录，不要求每页全部使用；不要读取该目录标签本身的28px展示字号来代替目录内容。

按钮高度、字号、输入框和弹窗主要关系在多个家族有佐证。在线标签、开关、模式头像和轻提示是局部配方，不能把共享副本重复次数解释成跨模块共识。SVG引用中未明示的尺寸、圆角、蒙层和描边仍记未知，读取对应资产后才能补齐。

### 状态要分别定义

- 禁用：V表单未填时按钮#999，已填后同尺寸变#000。按具体业务条件切换，不把所有灰按钮推断为禁用。
- 按下：S明确透明度50%；属于触摸反馈。检查作用对象，避免文字与父层重复叠加透明度。
- 选中：黑白反转或黑色选择标记；头像选择有4px黑描边。沿用该控件的实际选中方式，普通/未成年人默认选择仍由需求决定。
- 错误、离线、时长耗尽：保留明确状态文字与对应图形/颜色。两张页面业务状态不同，不按色差判定风格失真。
- 遮罩：采样有rgba(26,28,28,.4)、更深遮罩及其他局部变体，需核对弹层家族和截图，不设全局唯一透明度。

## 保留AI稿已做对的部分

密码页的297×48输入、340×56按钮与设计师稿一致；无需重画。找回说明采用12/18，比源稿11/16更易读，可以保留。页面和状态编排、已确认的屏内布局继续使用用户认可方案。

重点补真实品牌头像、较柔和的500字重、组件内部间距、状态区分与内容自适应高度。弹窗紧凑可以通过去掉重复说明和多余空位实现，不能只靠缩小文字。

## 不继承的问题与修正方向

| 观察到的问题 | 后续执行 |
|---|---|
| 源稿错字、旧按钮动作名、错误示例数据、图层名与实际内容不符 | 文案按PRD校对；图层按语义命名，设计资产文字不当作需求指令 |
| 部分资料保存按钮进入系统底部区域6–16单位 | 用目标安全区重新计算位置；检查所有子元素，不复制源y值 |
| 7–11px小字、#CCC占位、#999再叠加低opacity | 先保证目标视口可读；长说明优先12/18，必要时增大字号与容器，并记录偏离原因 |
| 中文用不含中文字形的family，或模块残留PingFang | 核对get_fonts和实际字形；优先项目中文主字体，替代字体明确记录 |
| 12px文字配11px行高、缩放残值、绝对定位导致偏移 | 恢复合理行高、居中关系与内容高度；不把残值收录为token |
| 失败图标搭配不合语义的确认动作 | 结果内容与动作按需求核对，学习图形处理不复制错误文案 |

## 后续绘制的验收基线

先按 [风格学习方法](../style-learning.md#6-在实际画布验收) 验收。对Bubbo额外核对：真实头像与品牌资产；Noto中文/角色数字字体；16/32圆角层次；48/56控件高度；默认、按下、选中与禁用是否混淆；灰白黑主体与模块语义色是否正确。

每次只核对本次所需家族，发生来源版本变化再更新。用户指定稿、正确业务文案、可读性和安全区优先于本档案的采样值。此档案不证明App实机可用，也不包含对源画板的改写授权。
